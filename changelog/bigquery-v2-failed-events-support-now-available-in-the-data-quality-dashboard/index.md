We are pleased to announce that the **Data Quality Dashboard** now fully supports **BigQuery V2 Failed Events Loaders,** enabling deeper visibility into failed events across your Snowplow pipelines on **AWS** and **GCP**.

With this release, you can now:

* **Monitor failed events** loaded via BigQuery V2 directly within the Data Quality Dashboard.
* **Drill into data quality issues** across your BigQuery failed events datasets -- whether you are using AWS or GCP.
* **Toggle between multiple sources**: Seamlessly enable or disable the Data Quality Dashboard add-on for specific failed event loaders, making it easy to switch between Snowflake and BigQuery.

This new functionality empowers data teams using BigQuery to quickly inspect and resolve tracking issues faster, all while keeping full control over data privacy.

To learn more about how to use this feature, visit our [documentation](/docs/monitoring/).
