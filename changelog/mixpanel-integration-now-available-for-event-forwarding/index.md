Snowplow now supports [Mixpanel](http://mixpanel.com/) as an Event Forwarding destination. This integration lets you send Snowplow events to Mixpanel in real-time using Mixpanel's [Import API](https://developer.mixpanel.com/reference/import-events). You can configure new Mixpanel forwarders directly in Snowplow Console, and they include pre-configured field mappings to make it easy to get up and running in minutes.

Mixpanel is a product analytics platform that helps companies analyze user interactions with web and mobile applications.

To learn more, see the [documentation](/docs/destinations/forwarding-events/integrations/mixpanel/).
