Like warehouses and other systems, data lakes should be optimized for best performance (efficiency of data ingestion, query speed, and so on).

Following the earlier [Lake Loader announcement](/changelog/self-served-lake-loader-setup-now-available/), we have now published a guide for tuning Delta and Iceberg lakes as destinations for Snowplow data: /docs/api-reference/loaders-storage-targets/lake-loader/maintenance/.

If you are using Snowplow Lake Loader, please follow this guide to get the most out of your lake.
