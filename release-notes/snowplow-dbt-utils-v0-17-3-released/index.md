We’re pleased to announce a new [release](https://github.com/snowplow/dbt-snowplow-utils/releases/tag/0.17.3) for Utils.

### **Summary**

This release introduces a macro to enable snowplow dbt repos to validate user license acceptance.

### **Features**

* This release introduces the macro `license_check` for use by snowplow dbt repos to validate user license acceptance.

### **Upgrading**

Update the snowplow-utils version in your `packages.yml` file.
