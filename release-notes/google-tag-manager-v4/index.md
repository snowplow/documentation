We're happy to announce the release of v4 of the Snowplow GTM templates.

This release adds two new templates, which you can find in the GTM gallery; [Snowplow v4](https://tagmanager.google.com/gallery/#/owners/snowplow/templates/snowplow-gtm-tag-template-v4) and [Snowplow v4 Settings](https://tagmanager.google.com/gallery/#/owners/snowplow/templates/snowplow-gtm-variable-template-v4).

As the Snowplow v4 tag is now based on the v4 release of the JavaScript tracker, it enjoys all the benefits included in the update, including async cookie access for better performance, and other tweaks and fixes.

The plugins that are bundled by default with the template have also changed, with deprecated plugins being removed and commonly used plugins being included. A full list of plugin changes is available on the [JavaScript v3-v4 migration guide](/docs/sources/web-trackers/migration-guides/v3-to-v4-migration-guide/#plugin-changes).

The documentation has also been updated to cover more common use-cases, along with a better quick-start experience, making getting set up with the Snowplow tags easier than ever.
