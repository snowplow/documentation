We are excited to introduce the **Event Catalog**, a new centralized view in the Snowplow Console that provides a comprehensive list of all your event specifications in one place. The Event Catalog improves discovery, observability, and searchability across your tracking implementation, making it easier to manage and govern your behavioral data collection.

## What's new

The Event Catalog brings all your event specifications together in one searchable, filterable list with key metrics and status information:

**Centralized event discovery**: Access all event specifications across your tracking plans in one unified view, eliminating the need to navigate through individual tracking plans to find specific events.

**Filtering and sorting**: Quickly locate events using multiple filter and sort options including event name, status (draft or published), entities, tracking plan, volume, and last seen timestamp.

**Event observability**: Monitor event activity with volume metrics (events received over the last 30 days) and last seen timestamps, helping you identify active events and spot potential implementation issues.

## Event Catalog and Tracking Plans

The Event Catalog complements your existing Tracking Plans workflow:

* **Tracking Plans** remain the logical grouping mechanism for organizing event specifications, supporting implementation workflows and governance practices.
* **Event Specifications** represent your business events and define how events are implemented using data structures.
* **Event Catalog** provides a centralized, searchable view across all event specifications, regardless of which tracking plan they belong to.

## Getting started

The Event Catalog is available now to all Event Studio customers.

To access it, navigate to **Data collection > Event catalog** in the Snowplow Console.
