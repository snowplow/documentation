We’re excited to introduce the Snowplow MCP Server for Tracking Design, a new tool that enables data engineers, product managers, and analysts to collaborate with AI to design future-proof Snowplow tracking faster.

The Snowplow MCP Server for Tracking Design uses the snowplow-cli, our command-line (CLI) tool and API to provide tools for validating and working with data products and data structures to AIs. The tool also understands and recommends Snowplow tracking best practices, accelerating the tracking design process, and accelerating time-to-value with new use-cases.

This is available from the [0.1.2](https://github.com/snowplow/snowplow-cli/releases) release of the Snowplow CLI onwards (part of Data Product Studio).

To learn more, check out the [tutorial](/tutorials/snowplow-cli-mcp/introduction/) on our documentation site, or watch the [demo video](https://vimeo.com/1096253323).
