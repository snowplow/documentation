Snowplow skills connect your AI assistant, such as Claude, Cursor, Codex, or another MCP-compatible tool, to your Snowplow account. With a skill, your assistant can work with your pipelines, schemas, and Console data directly instead of describing them.

Every skill requires a one-time connection to the [Snowplow MCP server](/docs/ai/snowplow-mcp/index.md), which links your AI assistant to your Snowplow Console account. The first time you use a skill, you'll be prompted to log in and authorize access.

## Install the skills

The skills are published as a plugin in the [`snowplow/skills`](https://github.com/snowplow/skills) GitHub repository. To install them in Claude Code, run:

```txt
/plugin marketplace add snowplow/skills
/plugin install snowplow@snowplow
```
